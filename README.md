## About

I'm Taha, a software engineering student at the University of Haripur and the founder of CodeCraft Official, where I build Flutter apps, web platforms, and AI automations for people who want one person to own the whole build instead of coordinating three freelancers.

Most of my work sits between product and AI. I ship cross-platform apps with Flutter and Firebase, build agentic systems with LangChain, and automate the repetitive parts of a business with n8n. Before any of this I spent a year teaching AI and Computer Science to high schoolers at St. Peter's High School in Taxila, which taught me more about explaining hard ideas simply than most of my coursework did.

Right now I'm building Socian, a Flutter social app, and MedSync, a multi-tenant healthcare platform. I care about how an app feels to use, not just whether it runs.

**Open to:** internships · freelance projects · full-time roles · collaborations on AI and product work

## Featured Projects

<details open>
<summary><b>Socian — Flutter Social App</b></summary>

<br/>

A Flutter and Firebase social app with over 15 screens and a dark glassmorphic interface. I applied data structures and algorithms to the backend and added features most social apps skip, like usage reminders and a chat lock.

| | |
|---|---|
| **Stack** | Flutter · Firebase · Firestore · Dart |
| **Scale** | 15+ screens, real-time feed and messaging |
| **Performance** | DSA-applied backend for efficient feed and lookups |
| **Security** | Firebase Auth, per-chat lock, rule-based access |
| **Impact** | Full social experience with retention-minded extras |
| **Repository** | [View on GitHub](https://github.com/Muhammad-Tahaa-Awan) |

Built the whole thing solo, from UI to data model. The chat lock and usage reminders came from wanting the app to respect a user's time rather than just maximize screen time.

</details>

<details>
<summary><b>MedSync — Healthcare SaaS Platform</b></summary>

<br/>

A multi-tenant healthcare platform for clinics and hospitals in both local and international markets. It splits into a clinic web portal, a patient app, a doctor app, and a super admin panel, with role-based access throughout.

| | |
|---|---|
| **Stack** | Flutter · Firebase · Gemini API |
| **Scale** | Four surfaces, multi-tenant by design |
| **Performance** | Adaptive workflows driven by Gemini |
| **Security** | Role-based access control across every portal |
| **Impact** | One codebase serving clinics, doctors, and patients |
| **Repository** | [View on GitHub](https://github.com/Muhammad-Tahaa-Awan) |

The hard part here was tenancy: keeping each clinic's data isolated while sharing one platform. I also researched local and international billing so the product can charge in PKR and USD without rebuilding.

</details>

<details>
<summary><b>DriveForge — 3D Car Customization App</b></summary>

<br/>

A 3D car customization app concept, planned as a phased solo-developer MVP. Flutter handles the app shell, Unity renders the 3D layer, and Gemini powers the smarter interactions.

| | |
|---|---|
| **Stack** | Flutter · Unity · Firebase · Gemini API |
| **Scale** | Phased MVP, single-developer scope |
| **Performance** | Unity 3D layer embedded in a Flutter app |
| **Security** | Firebase Auth and backend |
| **Impact** | Proof that a small team can ship real-time 3D |
| **Repository** | [View on GitHub](https://github.com/Muhammad-Tahaa-Awan) |

This one was about scoping. Bringing Unity and Flutter together is easy to over-plan, so I cut it into phases I could actually finish alone.

</details>
